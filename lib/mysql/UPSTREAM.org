The vendored =mysql.el= starts from that commit and carries two local patches.

First, ~mysql--send-packet~ sends each header and payload fragment in one socket
write.  Separate short writes can introduce a TCP delayed-ACK wait for every
command.  Fragment boundaries, sequence numbers, and wire bytes are unchanged.
The packet contract in [[file:../../tests/dorg-transport-tests.el][dorg-transport-tests.el]] covers empty, small,
exact-limit, and split payloads, including sequence wrap and empty terminators.

Second, the text-protocol row decoder ~mysql--parse-typed-value~ and the
prepared/binary string decoder ~mysql--binary-text-value~ decode wire bytes
with =utf-8-unix= instead of =utf-8=.  Plain =utf-8= applies automatic
end-of-line conversion, so a stored CRLF value read back as LF.  Binary-charset
and BINARY-flag columns and custom type parsers still receive the raw bytes.
The regressions and controls are in the same test file.

Both patches are local to DOrg; neither is an upstream release.
